# ADR 0010. Визуальный язык операционной консоли

**Статус:** принято · доводка после M6

## Контекст

Интерфейс, в котором оператор проводит смену, живёт по другим правилам,
чем витрина. Оператор смотрит на список из двух сотен строк и ищет
исключения: просроченный заказ, заказ без курьера, отменённый. Оформление
должно помогать этому поиску, а не соревноваться за внимание.

## Решения

### Приглушённая палитра, цвет как сигнал

Нейтральные тона холодные и малоконтрастные между собой, акцент один.
Семантических цветов три: успех, предупреждение, ошибка. В списке из 200 строк
насыщенный цвет означает исключение — если раскрасить всё, сигнал исчезает.

Статус передаётся **и цветом, и точкой, и текстом**: опора на один только цвет
недоступна части пользователей.

### Плотность и иерархия

Строка таблицы — три уровня: номер и клиент (основной вес), значения
(обычный), метаданные (приглушённый). Суммы и номера набраны
`font-variant-numeric: tabular-nums`, иначе цифры «пляшут» при прокрутке.

Шапка таблицы липкая: на двухстах строках колонки не должны теряться.

### Адаптивность через приоритет колонок, а не через второй макет

На узких экранах второстепенные колонки скрываются по порядку значимости
(изменён → создан → адрес → ресторан → курьер), а их содержимое сворачивается
в приглушённую подстроку под именем клиента. Это одна разметка вместо двух:
нет дублирования DOM, нет расхождения между «мобильной» и «десктопной» версией,
и таблица остаётся таблицей для скринридера.

Подстрока склеена в одну строку намеренно — так она не конкурирует
с отдельными колонками при точном поиске по тексту в тестах.

### Иконки — инлайн-SVG без библиотеки

Полтора десятка иконок не стоят зависимости на несколько сотен килобайт.
Все декоративные: `aria-hidden`, `currentColor`, из доступного имени кнопки
исключены.

### Движение

Только переходы цвета при наведении и индикатор фонового обновления.
`prefers-reduced-motion` отключает анимации целиком.

## Следствия

* Тёмная тема не сделана: для инструмента, которым пользуются при дневном
  свете в офисе, это преждевременно. Токены вынесены в `@theme`, так что
  добавление темы — правка одного файла, а не всех компонентов.
* Плата за приоритет колонок: на мобильном не видно курьера в списке —
  для этого нужно открыть карточку. Осознанный размен: колонка «курьер»
  на узком экране вытеснила бы сумму.

## Найдено при реализации

Первая версия подстроки под клиентом дублировала сумму, которая уже была
в своей колонке. Тест на поля таблицы это поймал: поиск по тексту находил
два элемента. Дубль убран — сумма осталась только в колонке, ширина колонки
клиента уменьшена. Проверка на «читается ли строка однозначно» оказалась
и проверкой на «не показываем ли мы одно и то же дважды».
